Computational literary research

Stevenson Text Research Explorer

A browser-based companion to the reproducible Python pipeline. It exposes the underlying tables rather than hiding analytical choices behind a visualization.

How to read this interface

Each view is generated from CSV or JSON outputs produced by the analysis pipeline. Counts and statistical measures are evidence for further reading, not conclusions about literary meaning.

Explore an output table

Research design

  • Structural divisions are stored as inspectable data.
  • Character aliases are explicit and version-controlled.
  • Frequency, dispersion, context, and comparative statistics are kept distinct.
  • Every displayed value remains available in a machine-readable table.
